# Steerings

Steerings are durable rules for how to change and review the current system.
They do not contain task numbers, status or historical measurements.
If a rule changes, update its steering in the same change.

- [invariants.md](invariants.md) — product scope, recording and processing, runtime and data, parallel agent rules. Obey them in every change.
- [documentation.md](documentation.md) — where to put knowledge and how to write documents.
- [quality.md](quality.md) — test layers, checks for each type of change, domain and kind selection, resource limits, required evidence.
- [project-commands.md](project-commands.md) — what the test, typecheck, lint, build, Companion and app commands do, and their cost.
- [scripts.md](scripts.md) — inventory of `scripts/`, TypeScript tooling rules, local update.
